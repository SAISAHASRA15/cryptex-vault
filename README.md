# 🔐 Cryptex Vault

Cryptex Vault is a cybersecurity-focused web application developed as a university project. It provides users with security-related tools and information through a simple and responsive web interface.

## 🚀 Features

- User Login
- Dashboard
- Password Strength Checker
- Cybersecurity Services
- Threat Information
- Incident Reporting
- Contact Form
- Responsive Web Design
- Server-side validation
- JSON-based data storage

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Node.js
- Express.js
- JSON
